# EyeRest

> 장시간 화면 작업 중 사용자가 눈 휴식 행동을 실천하도록 돕는 웹 프로토타입입니다.

## 프로젝트 소개

EyeRest는 과제, 온라인 강의, 문서 작성 등으로 PC 화면을 사용하는 대학생을 주요 대상으로 합니다. 사용자는 현재 주관적으로 느끼는 눈의 불편 정도를 입력하고, 원하는 작업시간을 직접 선택해 작업 타이머와 휴식 안내를 이용할 수 있습니다.

EyeRest는 의료기기나 진단·치료 프로그램이 아닙니다. 입력 점수와 안내는 사용자의 응답과 휴식 행동을 정리하기 위한 프로토타입 기능이며, 질환이나 치료 효과를 판정하지 않습니다.

## 이용 흐름

1. 눈의 피로, 건조감, 흐릿함, 눈 통증·압박감을 각각 0–5점으로 입력합니다.
2. 총점과 초기 불편 수준 요약을 확인합니다.
3. 10분, 15분, 20분 또는 직접 설정(1–120분) 중 작업시간을 선택합니다.
4. 작업 타이머를 시작하고 필요하면 일시 정지, 재개 또는 세션 종료를 선택합니다.
5. 작업 주기가 끝나면 20초 휴식 타이머가 표시됩니다. 휴식을 완료하거나 연기할 수 있습니다.
6. 세션을 종료하면 실제 작업시간, 선택한 작업시간, 휴식 완료·연기 횟수와 휴식 수행률을 확인합니다.

## 주요 기능

- 증상별 슬라이더와 설명 툴팁
- 점수 입력 기준과 이용 안내 패널
- 총점 계산 및 초기 불편 수준 요약
- 사용자가 선택하는 작업시간
- 작업 타이머의 시작, 일시 정지, 재개 및 종료
- 20초 휴식 타이머와 휴식 완료·연기 기록
- 실제 작업시간과 휴식 수행률을 보여주는 세션 결과
- 새 세션 시작 및 입력 초기화

## 근거와 설계 가정

디지털 눈 피로와 관련된 증상 및 평가 도구는 연구되어 왔지만, EyeRest의 입력 항목과 점수 규칙은 검증된 진단 척도가 아닙니다. 아래와 같이 문헌 근거, 프로토타입 가정, 앞으로 확인할 사용자 요구를 구분합니다.

### 설계 항목별 근거와 한계

#### 눈 관련 증상

피로, 건조감, 흐릿함, 눈 통증·압박감을 간결한 입력 후보로 사용합니다. 컴퓨터 시각 증상 설문(CVS-Q)은 문헌·전문가 검토, 예비·파일럿·재검사와 심리측정 평가를 거쳐 16개 증상을 다루도록 개발됐습니다. EyeRest의 네 항목은 간단히 줄여 구성한 후보이며, 별도로 타당화되지 않았습니다.

#### 0–5점과 총점 구간

네 항목에 같은 비중을 적용해 합산하고 0–5, 6–12, 13–20점으로 요약합니다. 이는 초기 화면 설계 규칙입니다. 가중치와 구간은 임상 기준이 아니며 질환이나 위험도를 판정하지 않습니다. 사용자가 점수 기준을 이해하는지도 아직 평가하지 않았습니다.

#### 작업시간 선택

사용자가 10·15·20분 또는 직접 설정을 선택합니다. 이 선택지는 사용 편의를 위한 초기 옵션이며, 어느 시간이 최적이거나 의학적으로 권장된다는 의미는 아닙니다.

#### 20초 휴식

작업 주기가 끝나면 20초 휴식 타이머를 보여줍니다. 30명이 태블릿 읽기 과제를 수행한 연구에서는 여러 예약 휴식 간격이 증상, 읽기 속도, 정확도에 유의한 차이를 보이지 않았습니다. 2026년 100명의 건강한 성인을 대상으로 한 노트북 게임 실험에서는 일부 시각 기능 지표의 차이가 보고됐습니다. 과제와 측정 지표가 다르므로 어느 연구도 EyeRest의 설정 효과를 직접 입증하지 않습니다.

#### 대학생의 실제 요구

요구조사와 사용성 평가를 계획하고 있으나 아직 실시하지 않았습니다. 따라서 대학생의 증상 빈도나 기능 선호에 관한 조사 결과는 없으며, 현재는 사용자 요구를 확인하기 위한 계획만 제시합니다.

## 사용자 조사 계획

### 요구조사

**상태: 미실시.** 대학생 10–20명을 대상으로 익명 탐색 설문을 계획합니다. 이 규모의 편의 표본은 설계 의견을 모으기 위한 것이며, 전체 대학생의 증상 유병률이나 선호도를 추정하는 근거로 사용하지 않습니다.

조사할 내용:

- 수업·과제 중 하루 화면 사용시간과 주된 사용 상황
- 화면 사용 중 경험하는 불편과 휴식을 놓치거나 미루는 빈도
- 10·15·20분·직접 설정 선택지의 이해도와 선호
- 휴식 연기 기능과 세션 결과 화면의 필요성
- 입력 점수 기준과 결과 안내를 이해하기 쉬운지 여부

이름·연락처·진단명 등 불필요한 식별정보와 민감한 건강정보는 수집하지 않습니다. 설문을 진행하기 전 참여 목적, 자발적 참여, 응답 사용 범위와 보관·삭제 방식을 안내하고 수업 및 지도교수의 조사 지침을 확인합니다.

### 사용성 평가

요구조사와 별도로 학생 5–8명 규모의 초기 사용성 평가를 계획합니다. 자가점검, 작업시간 선택, 타이머 일시 정지·재개, 휴식 완료·연기, 세션 종료를 수행하게 하고 과제 성공 여부, 혼동 지점, 오류와 개선 의견을 기록합니다. 이 평가는 사용 편의와 이해도를 살펴보는 것으로, 의료적 효과를 검증하지 않습니다.

## 안전 및 한계

- 입력 점수와 구간은 의료적 진단이나 치료 권고가 아닙니다.
- 네 증상 항목, 동일 가중치 합산, 구간별 문구는 초기 프로토타입 설계입니다.
- 10·15·20분과 20초는 사용자가 선택하거나 시험해 볼 수 있는 초기 설정이지, 효과가 확립된 기준이라는 뜻이 아닙니다.
- 사용자가 직접 입력하므로 실제 의학적 상태를 측정하지 않습니다.
- 갑작스러운 시력 변화, 지속적인 통증 또는 심한 불편이 있으면 전문가와 상담하도록 안내합니다.
- 브라우저 탭이나 페이지를 닫으면 진행 중인 세션은 이어지지 않습니다.

## 개인정보 및 데이터 처리

- 웹캠 영상, 생체 신호, 이름, 연락처를 요청하지 않습니다.
- 현재 버전은 입력값과 세션 기록을 `localStorage`에 저장하거나 외부 서버로 전송하지 않습니다.
- 세션 결과는 페이지가 열린 동안에만 유지되며, 새로고침하거나 페이지를 닫으면 사라집니다.
- 향후 저장 기능을 추가할 경우 저장 항목, 삭제 방법과 브라우저별 보관 한계를 별도로 안내할 예정입니다.

## 기술 및 실행 방법

별도 빌드 과정이나 외부 JavaScript 라이브러리 없이 HTML, CSS, JavaScript로 실행합니다.

### 로컬 서버 실행

Visual Studio Code에서 `TY_1-1/EyeRest` 폴더를 열고 Live Server로 `index.html`을 실행하거나, PowerShell에서 `EyeRest` 폴더로 이동해 다음 명령을 실행합니다.

```powershell
py -m http.server 8080
```

브라우저에서 `http://localhost:8080/`으로 접속합니다. 서버를 종료하려면 실행 중인 터미널에서 `Ctrl + C`를 누릅니다.

### 프로젝트 구조

```text

├── README.md
├── .vscode/
└── EyeRest/
    ├── index.html

    └── script.js
```
