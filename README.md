# EyeRest

> 장시간 화면 작업 중 사용자가 현재 눈의 불편 상태를 확인하고, 작업과 눈 휴식 행동을 관리할 수 있도록 지원하는 반응형 웹 프로토타입입니다.

## 1. 프로젝트 개요

EyeRest는 과제, 온라인 강의, 문서 작성 등으로 PC 화면을 오래 사용하는 대학생을 주요 대상으로 합니다. 사용자는 현재 느끼는 눈 관련 불편 정도를 직접 입력하고, 원하는 작업 주기를 선택해 작업 타이머와 휴식 안내 기능을 사용할 수 있습니다.

EyeRest는 의료기기나 진단 프로그램이 아닙니다. 입력 결과는 사용자의 주관적인 상태를 정리하고 눈 휴식 행동을 지원하기 위한 참고 정보입니다.

## 2. 프로젝트 목표

- 장시간 화면 작업 중 눈 휴식 시점을 놓치는 문제를 줄입니다.
- 현재 느끼는 눈의 불편 상태를 작업 전에 간단히 확인할 수 있도록 합니다.
- 사용자가 작업시간을 직접 선택하고 정기적인 휴식을 실천하도록 지원합니다.
- 휴식 완료 및 연기 행동을 기록해 작업·휴식 습관을 확인할 수 있도록 합니다.
- 별도 센서, 웹캠, 회원가입 없이 사용할 수 있는 웹 프로토타입을 구현합니다.

## 3. 주요 기능

### 3.1 눈 상태 자가점검

다음 네 가지 항목을 슬라이더로 입력합니다.

- 눈의 피로
- 건조감
- 흐릿함
- 눈 통증·압박감

각 증상명 옆의 작은 `i` 버튼에 마우스를 올리거나 버튼을 클릭하면 항목 설명을 확인할 수 있습니다.

### 3.2 입력 안내 최소화

기본 화면에는 입력에 필요한 요소만 표시합니다.

- 증상별 상세 설명: `i` 버튼으로 확인
- 점수 입력 기준: `점수 입력 기준 안내` 버튼으로 펼치기
- 의료적 이용 안내: `이용 안내` 버튼으로 펼치기

### 3.3 작업시간 선택

시스템이 특정 작업시간을 의학적 기준처럼 확정하지 않습니다. 사용자가 다음 선택지에서 작업 주기를 결정하도록 구성할 예정입니다.

- 10분
- 15분
- 20분
- 직접 설정

### 3.4 작업 타이머

- 작업 시작
- 남은 시간 표시
- 일시 정지
- 계속하기
- 작업 종료
- 중복 타이머 실행 방지

### 3.5 휴식 안내

작업시간이 끝나면 휴식 화면을 표시합니다.

- 화면에서 시선을 떼고 먼 곳 바라보기 안내
- 휴식 타이머
- 휴식 완료
- 나중에 하기
- 완료 및 연기 횟수 기록

### 3.6 세션 결과

작업 종료 후 다음 정보를 제공하도록 확장할 예정입니다.

- 실제 작업시간
- 선택한 작업 주기
- 휴식 완료 횟수
- 휴식 연기 횟수
- 휴식 수행률
- 작업 전후 자가 입력 변화

## 7. 실행 방법

### Visual Studio Code와 Live Server 사용

1. Visual Studio Code에서 `EyeRest` 폴더를 엽니다.
2. Live Server 확장을 설치합니다.
3. `index.html`을 마우스 오른쪽 버튼으로 클릭합니다.
4. `Open with Live Server`를 선택합니다.
5. 브라우저에서 다음과 유사한 주소가 열리는지 확인합니다.

```text
http://127.0.0.1:5500/index.html
```

`file:///` 경로로 직접 실행하면 브라우저 보안 정책에 따라 일부 기능에서 문제가 발생할 수 있으므로 로컬 서버 실행을 권장합니다.

### Python 로컬 서버 사용

Windows PowerShell에서 프로젝트 폴더로 이동한 후 실행합니다.

```powershell
cd C:\Users\사용자이름\Documents\GitHub\TY\EyeRest
py -m http.server 5500
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:5500/index.html
```

서버 종료는 터미널에서 `Ctrl + C`를 누릅니다.

## 9. 설계 근거와 현재 한계

EyeRest의 핵심 목표는 질환을 판정하는 것이 아니라 눈 휴식 행동을 지원하는 것입니다. 현재 증상 항목, 입력 척도, 불편 수준 구간과 시간 제안값 중 일부는 사용자 평가 전의 초기 설계 가정입니다.

따라서 다음 원칙을 적용합니다.

- 입력 결과를 질환명이나 의료적 위험도로 표시하지 않습니다.
- 점수는 임상 진단 점수가 아니라 현재 주관적 불편을 정리하기 위한 값으로 사용합니다.
- 특정 작업시간을 의학적 권장시간으로 단정하지 않습니다.
- 최종 작업시간은 사용자가 선택하도록 설계를 보완합니다.
- 사용자 요구조사와 사용성 평가 결과에 따라 증상 항목과 안내 방식을 수정합니다.

## 11. 의료적 안전 안내

> EyeRest는 사용자의 눈 휴식 행동을 지원하기 위한 웹 프로토타입이며 질환을 진단하거나 치료하지 않습니다. 갑작스러운 시력 변화, 지속적인 통증 또는 심한 불편이 있는 경우 프로그램 결과에 의존하지 말고 의료 전문가와 상담하시기 바랍니다.

## 12. 개인정보 및 데이터 안내

- 웹캠 영상과 생체 신호를 수집하지 않습니다.
- 이름, 연락처와 같은 개인정보 입력을 요구하지 않습니다.
- 기록 기능을 구현할 경우 데이터는 사용자의 현재 브라우저 내부에 저장합니다.
- 브라우저 데이터 삭제 시 저장 기록이 함께 삭제될 수 있습니다.
- 다른 브라우저나 기기와 기록이 자동으로 동기화되지 않습니다.
